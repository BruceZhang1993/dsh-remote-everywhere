# 0.2.0-rc.6 发布说明

宿主基线为 DSH Desktop `0.2.1-rc.2`，六个公共 npm 包统一为 `0.2.0-rc.6`，Android versionCode 为 `8`，沿用正式签名与包名。

## 修复范围

- 修复移动端首次配对后再次点击已配对设备仍要求输入地址，以及冷启动后连接地址丢失的问题。每台设备保存最近 8 个成功连接地址，点击时直接使用最近一次地址。
- 设备菜单「连接地址」可切换历史局域网／公网地址或输入新地址。失败连接不覆盖历史，重复地址去重并按最近成功使用排序。
- 历史地址与固定公钥、设备信任一同保存在平台安全存储；改名保留历史，移除本机记录同时删除历史。串行保存设备资料，防止并发写入恢复已移除的设备。
- 地址只用于定位，连接仍校验原配对公钥。沿用当前传输限制：WSS 或本机回环 WS，本版没有扩展局域网明文 WS。配对 sid、会话正文不落盘。

## 验证与发布

本地 Flutter 静态检查、26 项单元／界面测试和 5 项 Flutter／Node 集成测试通过。覆盖首次配对保存地址、冷启动恢复后实际重连、历史地址选择及手动更新、旧设备记录兼容、失败连接保留历史、地址数量限制、改名保留与移除清理、并发设备写入。

发布流水线针对最终标签重新验证，生成正式签名 APK，发布六个 npm 包到 `next`，验证匿名安装和管理 UI，再校验六个附件后公开 GitHub Release。预发布保留既有 `latest`；GitHub Packages 仍为独立可选渠道。

发布入口：[v0.2.0-rc.6](https://github.com/BruceZhang1993/dsh-remote-everywhere/releases/tag/v0.2.0-rc.6)。该链接及源码说明不代替流水线完成证明；以实际 Release 附件和 npm 确切版本为准。

## 升级与验收边界

Android 安装本版 APK 即可获得地址历史功能；保留 App 数据和正式签名升级即可，无需重新配对。旧版本没有落盘的地址无法追溯，已有设备需补录一次成功连接地址；新配对会直接保存地址。隧道地址失效时可更新地址，固定公钥不变。

本地测试不代表用户真机已验收。本版继续保留独立 Noise 安全审查、完整供应链及许可证独立审查、Android ARM 真机、iOS/macOS、真实模型、完整 UI/网络切换、既有 profile 升级/回滚及持续长期 fuzz 等延期项。
